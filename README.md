# TripNest – React + Tailwind website

Run: `npm install && npm run dev` · Build: `npm run build`

- Stack: React 19, Vite, Tailwind CSS v4, react-icons. Routing is a tiny built-in hash router (no extra dependency).
- Colours: only `navy` (#13234f) and `teal` (#0e8a85) – edit in `src/index.css` (`@theme`).
- Pages: Home, Services, For Business (B2B), Contact, Login, Signup (Traveller / Business switch).
- Auth is a front-end demo (localStorage) – replace `login`/`signup` in `src/auth.jsx` with your API.
- Placeholder content to replace: stats (25,000+, 400+, 98%), testimonials, prices (฿), partner plans.
